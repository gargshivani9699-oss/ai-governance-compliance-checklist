# ISO/IEC 42001 — AI Governance Compliance Checklist

## 1. Purpose

This checklist provides a structured approach to assessing an organization's AI Management System (AIMS) against selected requirements of ISO/IEC 42001:2023.

The assessment focuses on governance, leadership, planning, operational controls, performance evaluation and continual improvement.

**Assessment type:** Educational portfolio assessment  
**Assessment scenario:** Hypothetical organization using AI-powered recruitment software  
**Reference standard:** ISO/IEC 42001:2023

## 2. Assessment Status Definitions

| Status | Description |
|---|---|
| Compliant | Requirement is implemented with supporting evidence |
| Partially Compliant | Requirement is only partially implemented |
| Non-Compliant | Requirement is not adequately implemented |
| Not Verified | Sufficient evidence is unavailable |
| Not Applicable | Requirement does not apply to the assessment scope |

## 4. Important Assessment Considerations

- A documented policy does not automatically prove effective implementation.
- Evidence should be reviewed before assigning a compliance status.
- Missing evidence should be classified as Not Verified until further investigation.
- Risk treatment actions should have assigned owners and target dates.
- Corrective actions should be closed only after effectiveness is verified.

## 5. Assessment Limitations

This checklist is a practical, self-developed assessment aid based on selected ISO/IEC 42001:2023 requirements. It is not a reproduction of the complete standard.

The questions are paraphrased assessment prompts, not verbatim ISO clauses. A formal conformity assessment requires examination of the complete applicable standard, organizational context and relevant documented information.

## 6. Conclusion

This checklist supports a structured review of an organization's AI Management System. It helps identify governance weaknesses, evidence gaps and opportunities for improvement across the AI lifecycle.
